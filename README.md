# 🧠 Mental Health in Tech Survey — Analysis

Analyzes the OSMI 2014 "Mental Health in Tech" survey (1,259 raw responses)
to understand demographics, geography, workplace policy, attitudes/stigma,
and the strongest predictors of treatment-seeking behavior — per the project brief.

## Project structure

```
mh_project/
├── data/
│   ├── survey.csv                  # raw OSMI dataset (as provided)
│   └── survey_cleaned.csv          # generated by app.py
├── db/
│   └── mental_health.db            # generated by app.py (SQLite)
├── app.py                          # ETL: load → clean → engineer → save (CSV + SQLite)
├── Mental_Health_EDA.ipynb         # full data cleaning + exploratory analysis notebook
├── dashboard.py                    # Streamlit interactive dashboard
├── requirements.txt
└── README.md
```

## How to run

```bash
pip install -r requirements.txt
python app.py                # builds the cleaned CSV + SQLite DB
streamlit run dashboard.py   # launches the dashboard
```

The dashboard is **self-healing**: if `db/mental_health.db` is missing (e.g. a
fresh deploy where only the `.py` files were committed) it will automatically
run the pipeline on first load, as long as `data/survey.csv` is present.

## Data cleaning highlights

The raw survey export has two classically messy fields, both handled in `app.py`:

- **`Gender`** — 40+ free-text variants ("Male", "M", "Cis Male", "Malr",
  "Woman", "cis-female/femme", ...) standardized into `Male` / `Female` /
  `Other/Unspecified`.
- **`Age`** — contains data-entry errors including negative values and
  `99999999999`. Rows outside a plausible 15–90 range are dropped (8 of 1,259).

Other handling: `work_interfere` missingness is mapped to "Not applicable"
(it correlates almost perfectly with not having sought treatment — the
question is conditional); `self_employed` missing values filled with the
mode; `comments` (87% empty free text) converted to a boolean flag rather
than analyzed as text.

**Engineered features:** `Age_Group`, `Gender_Clean`, `Is_US`,
`Treatment_Flag`, `Family_History_Flag`, and a composite
`Workplace_Support_Score` (0–5, counting "Yes" answers across benefits,
care_options, wellness_program, seek_help, and anonymity).

## What the dashboard covers

| Tab | Content |
|---|---|
| Overview | KPI cards, treatment split, gender/age/company-size distribution |
| Geography | Treatment rate by country, top countries & US states by volume |
| Demographics | Age/gender vs. treatment, treatment rate by age group and gender |
| Workplace Factors | Policy vs. treatment rate, support score, remote work, medical leave |
| Attitudes & Stigma | Mental vs. physical health disclosure consequences, interview willingness |
| Family History & Interference | Family history vs. treatment, work-interference distribution |
| Predictors of Treatment | Paired-comparison chart of strongest predictors, correlation heatmap |
| Explore Raw Data | Filtered table + CSV download |

All tabs respond to the sidebar filters (country, gender, age group, company
size, tech-company-only, treated-only, family-history-only).
